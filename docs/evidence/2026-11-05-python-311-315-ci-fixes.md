## Change

The first public CI run failed on Python 3.10 and macOS. As the owner chose, Python 3.11 is now the minimum
(3.10 reached end of life in October 2026); CI tests 3.11-3.14 on Ubuntu and latest stable 3.15 on Windows and
macOS. Quality and Copilot setup jobs use 3.15; the cross-engine job uses 3.14 while pyodbc lacks 3.15 wheels
([ADR 0014](../design/adr/0014-python-311-minimum-and-315-primary.md)).
Tool targets move to 3.11; Ruff applied behavior-preserving 3.11 modernizations, and SQLite errors use named constants.
The viewer test now proves an active request is destroyed promptly and accepts macOS's valid reset outcome.

## Gaps and risks

- On Python 3.15, `local` (fastembed/onnxruntime) and `mssql` (pyodbc) cannot install from upstream wheels yet;
  README, CHANGELOG and ADR 0014 direct those users to Python 3.11-3.14. The external-engine job uses 3.14.
- Windows and macOS test only Python 3.15. Python 3.10 users must upgrade.
- The pre-existing resource warnings remain; no gate was lowered.
