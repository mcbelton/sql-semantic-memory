## Checklist

- **Correctness:** pass. `datetime.UTC` is the same object as `timezone.utc` (3.11+). The built-in
  `TimeoutError` is what `asyncio.wait_for` raises in 3.11+ (`asyncio.TimeoutError` is an alias). The SQLite
  mapping is unchanged (`SQLITE_FULL`=13, `SQLITE_BUSY`=5, `SQLITE_LOCKED`=6, and "database table is locked"
  still maps to BUSY), and the string fallbacks still cover exceptions without a code. Error messages are
  unchanged. No behavior is hidden in the refactoring.
- **Missed 3.10 declarations:** none in active configuration or docs. `rg` across the repository finds 3.10
  only in history: CHANGELOG 0.2.0 at line 53, earlier evidence and review records, and the new ADR/evidence.
  No `sys.version_info` gates and no `tomli`/`typing_extensions` backports remain. The `py310` target is gone.
- **YAML quoting:** all `python-version`/matrix values are quoted strings (`"3.11"` … `"3.15"`), so a value like
  `3.10` can no longer collapse to a float. The flow mappings are valid.
- **SQL safety, privacy, secrets:** not affected. There are no SQL paths. No credentials appear in the diff,
  ADR or evidence. The CI password masking is unchanged.
- **Portability:** SQLite constants are stdlib-only. The dialect code is unchanged. Engines on 3.15 are not
  proven (finding 2).
- **Typing:** mypy/pyright target 3.11, so the typeshed version gates block newer stdlib APIs. No new
  `Any` or ignores were added.
- **Tests:** no Python test was weakened. `test_time_decimal_and_gaps` changes only the UTC spelling. The 3.10
  regressions are covered by the existing `test_fractional_datetime_order_is_chronological` and
  `test_projection_failure_commits_and_next_recall_repairs`, which ran on the 3.11 floor and on 3.15. For the
  Node test, see finding 3.
- **Docs/ADR:** ADR 0014 is present and indexed. CHANGELOG has Changed and Fixed entries. Findings 1, 4 and 5
  cover the gaps.
